LiDAR to CAD

USGS 3DEP bare-earth lidar, cut to your boundary and exported in Texas State Plane coordinates, ready for Civil 3D.

Coordinate system

Vertical datum NAVD88, feet.

Leave at 1 for grid coordinates. Enter the project's surface adjustment factor to output surface coordinates (scaled about 0,0).

Surface and contours

Run and export

The package adds a PNEZD point file, an Esri ASCII DEM grid and a README with the datum notes.

DXF opens straight into AutoCAD or Civil 3D at true State Plane coordinates. Run SAVEAS to make it a DWG, and set the drawing coordinate system to the zone code above. Elevations are the USGS 3DEP 1 m bare-earth DEM, which is built from lidar ground returns. Where no lidar exists, USGS fills the gap with coarser data, so check the source line after each run.
